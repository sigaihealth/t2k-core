# T2K 0.4: A Governed Integration Hub You Can Run Locally

T2K 0.4 turns the source-integration primitives introduced in 0.3 into a more
complete developer path: generate a working integration hub, expose its safe
computations to an AI agent, and persist human-reviewed canonical history with
lineage and exact rollback.

## What is new

- `create-t2k --profile integration-hub` generates a synthetic, runnable
  two-source hub with a shared canonical identity, preserved conflicts,
  explicit authority selection, deterministic reconciliation, and a pending
  human-review packet.
- `@t2kai/mcp` adds four safe-default tools for governed source mapping,
  canonical-reconciliation proposals, reversible entity-link proposals, and
  purpose-limited access evaluation.
- `@t2kai/core/postgres` adds immutable reconciliation proposals, explicit
  human dispositions, append-only canonical revisions, activation lineage, and
  exact rollback to an ancestor plus governed reactivation of an existing
  revision. Linked lifecycle execution receipts are snapshotted and digested
  into the proposal evidence rather than referenced as mutable rows.

## Try it

```bash
npx create-t2k@latest my-integration-hub --profile integration-hub
cd my-integration-hub
npm start
```

The output is an evidence packet, not a merged master record. Both generated
sources deliberately remain unauthenticated, all alternatives remain visible,
and the authority-selected value remains a proposal until a separate human
review and persistence path accepts it.

For the architecture, agent workflow, and production checklist, follow the
[integration-hub tutorial](../INTEGRATION_HUB_TUTORIAL.md).

## Human plus AI, with distinct authority

An AI agent can map records, compare provenance, propose entity links, route
ambiguous cases, and explain a purpose-access result. It cannot authenticate a
source, approve its own proposal, merge an entity, impersonate a human
reviewer, or enforce disclosure. T2K keeps those boundaries explicit while
letting agents and people complement one another in the same workflow.

## Package versions

- `@t2kai/core@0.4.0`
- `create-t2k@0.4.0`
- `@t2kai/mcp@0.3.0`

All packages require Node.js 20.10 or newer. The additions are backward
compatible with well-formed 0.3 source-integration inputs; existing
`create-t2k` invocations still generate the decision-loop profile by default.

T2K remains Apache-2.0. Hosted connectors, enterprise identity, managed
registry operations, customer data, and compliance services are separate from
the open reference runtime.
